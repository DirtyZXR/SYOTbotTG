# SYOTbotTG - Бот по охране труда

Telegram бот для работы с нормативной документацией, проведения тестирования (по электробезопасности и др.) и автоматического контроля сроков действия удостоверений.

## Особенности и функционал

- 🔐 **Аутентификация**: Регистрация новых пользователей через бота с обязательным подтверждением (апрувом) со стороны администратора.
- 📚 **Файловый браузер**: Интерактивный просмотр и скачивание документов по категориям через inline-клавиатуры. Файлы читаются напрямую из структуры директорий.
- 📝 **Тестирование**: Прохождение тестов по группам (в т.ч. электробезопасность) со случайной генерацией билетов и автоматической проверкой (успешная сдача — ≥90% правильных ответов).
- 🕒 **Фоновые задачи (Scheduler)**: Ежедневная проверка (в 08:00 МСК) сроков действия удостоверений. Рассылка предупреждений сотрудникам за 7 и 1 день, а также автоматическое уведомление администраторов и снятие допусков по истечении срока.
- 📊 **Трекинг активности**: Сохранение истории тестирования и логирование скачанных документов.
- 🪟 **Приложение для Windows**: Работа в фоновом режиме (System Tray) с возможностью упаковки в единый `.exe` файл для удобного деплоя.

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение (рекомендуется Python 3.12):
```bash
py -3.12 -m venv venv
```

3. Установите зависимости:
```bash
venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Создайте файл `.env` (можно скопировать из `.env.example`) и заполните его:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=your_telegram_admin_id_here
DATABASE_PATH=./data/bot.db
DOCUMENTS_PATH=./data/documents
```

### Запуск (Консольный режим)
```bash
venv\Scripts\python.exe main.py
```

### Запуск (Windows System Tray)
```bash
venv\Scripts\python.exe tray_app.py
```

### Сборка в EXE
Для сборки приложения в исполняемый файл Windows (в папку `dist/`) запустите скрипт:
```bash
build_exe.bat
```

## Использование (Команды бота)

Бот поддерживает следующие команды:

### Для сотрудников (пользователей)
- `/start` — **Главное меню**. Для новых пользователей автоматически запускает сценарий регистрации (ФИО, Email, выбор компании). После заполнения заявка отправляется администратору на рассмотрение.
- `/help` — Вывод справочной информации.
- `/cancel` — Отмена текущего действия (например, прерывание теста или регистрации).

*Внимание: Доступ к материалам и тестам открывается только после того, как администратор одобрит заявку.*

### Для администратора
- `/admin` — **Панель управления**. Доступ к статистике скачиваний, управлению доступами и результатам тестов.
- `/users` — **Управление пользователями**. Позволяет подтверждать (апрувить) новые заявки, изменять данные, отзывать допуски, а также вручную устанавливать/продлевать сроки действия удостоверений сотрудникам.

*(Примечание: Управление документами осуществляется напрямую через файловую систему сервера — достаточно разместить файлы в `DOCUMENTS_PATH`, и они автоматически появятся в боте. Никаких дополнительных команд для "загрузки" не требуется).*

## Структура папки с документами (`DOCUMENTS_PATH`)

Файловый браузер бота отражает реальную иерархию папок в директории `data/documents/`. Пример рекомендуемой структуры:

```text
data/documents/
├── гоичс/
│   ├── Инструкции/
│   └── Лекции/
├── охрана_труда/
│   ├── Инструкции/
│   └── Нормативная документация/
└── электробезопасность/
    ├── Билеты/
    └── Нормативка/
```

## Формат файла с тестами

Тесты хранятся в единственном JSON-файле по пути `data/tests/test.json`.
Бот генерирует билеты из массива вопросов случайным образом. Формат файла:

```json
{
  "group2": {
    "ticket_1": [
      {
        "question": "Какая минимальная группа по электробезопасности для выполнения работ под напряжением?",
        "options": [
          "Группа 1",
          "Группа 2",
          "Группа 3",
          "Группа 4"
        ],
        "correct_answer": "Группа 3"
      }
    ]
  },
  "group3": {
    ...
  }
}
```

## Технологический стек

- **aiogram 3.x** — Асинхронный фреймворк для Telegram Bot API
- **SQLAlchemy 2.x** — ORM для работы с БД
- **SQLite** — Легковесная база данных
- **Alembic** — Управление миграциями базы данных
- **Pydantic (v2)** — Удобная валидация данных и конфигурации
- **pystray / Pillow** — Реализация работы в системном трее Windows
- **PyInstaller** — Упаковка скриптов Python в `.exe`
