# SYOTbotTG - Бот по охране труда

Telegram бот для работы с документами по охране труда и прохождения тестов.

## Основные функции

- 🔐 Регистрация и верификация пользователей по коду безопасности
- 📚 Просмотр и скачивание документов по категориям
- 📝 Прохождение тестов по электробезопасности
- 📧 Уведомления администратора о результатах тестов

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение на Python 3.12:
```bash
py -3.12 -m venv venv
```

3. Установите зависимости:
```bash
venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example` и заполните его:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=your_telegram_admin_id_here
DATABASE_PATH=./data/bot.db
DOCUMENTS_PATH=./data/documents
SECURITY_CODE=123456
```

## Формат тестов

Создайте папку `data/tests` и добавьте JSON файлы с тестами:

```json
{
  "name": "Тест по электробезопасности (Группа 2)",
  "group": 2,
  "questions": [
    {
      "question": "Какая минимальная группа по электробезопасности для выполнения работ под напряжением?",
      "options": [
        "Группа 1",
        "Группа 2",
        "Группа 3",
        "Группа 4"
      ],
      "correct_answer": 2
    }
  ]
}
```

## Использование

### Для пользователей

1. **Регистрация**: `/register <email>`
2. **Верификация**: `/verify <код безопасности>`
3. **Главное меню**: `/start`
4. **Справка**: `/help`

### Для администратора

1. **Меню администратора**: `/admin`
2. **Список пользователей**: `/users`
3. **Установка кода безопасности**: `/setcode <код>`
4. **Загрузка документов**: `/load_docs`
5. **Загрузка тестов**: `/load_tests`

## Запуск

```bash
venv\Scripts\python.exe main.py
```

Если у вас уже был `venv`, созданный на Python 3.14, запустите `recreate_venv_312.bat` для пересоздания окружения под Python 3.12.

## Доступ к документам

- Доступ к документам возможен только после верификации
- Документы отправляются в формате PDF и других поддерживаемых Telegram форматах

## Прохождение тестов

- Выберите группу теста (2, 3 или 4)
- Ответьте на все вопросы
- Успешное прохождение: ≥90% правильных ответов
- Результаты с подсветкой: ✅ правильные, ❌ неправильные
- При успешном прохождении администратор получает уведомление

## Технологический стек

- **aiogram 3.x** - Telegram Bot API
- **SQLAlchemy 2.x** - ORM
- **SQLite** - База данных
- **Pydantic** - Валидация данных
