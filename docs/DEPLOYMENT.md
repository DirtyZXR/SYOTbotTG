# Руководство по установке и использованию

## Быстрый старт

### 1. Клонирование и установка

```bash
# Перейдите в папку проекта
cd C:\Users\d.zelinskii\Documents\Personal\SYOTbotTG

# Запустите скрипт инициализации
python init_project.py
```

### 2. Настройка .env файла

Откройте файл `.env` и заполните его:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
ADMIN_ID=123456789
DATABASE_PATH=./data/bot.db
DOCUMENTS_PATH=./data/documents
SECURITY_CODE=MY_SECRET_CODE_2024
```

**Как получить данные:**
- **BOT_TOKEN**: Напишите @BotFather -> `/newbot` -> выберите имя -> получите токен
- **ADMIN_ID**: Напишите @userinfobot -> получите свой ID

### 3. Добавление документов

Создайте структуру папок в `data/documents/` или запустите:

```bash
python setup_directories.py
```

Добавьте документы в соответствующие папки:

```
data/documents/
├── гоичс/
│   ├── Инструкции/
│   │   └── инструкция.pdf
│   └── Лекции/
├── охрана_труда/
│   ├── Инструкции/
│   └── Нормативная документация/
└── электробезопасность/
    ├── админ_тех_перс/
    │   ├── Билеты/
    │   └── Тесты/
    └── неэлектр_перс/
        └── Общие документы/
```

### 4. Запуск бота

```bash
python main.py
```

## Использование бота

### Для пользователей

1. **Регистрация**
   ```
   /register ivanov@intellektika.ru
   ```
   - Email должен быть с корпоративного домена (настраивается в коде)

2. **Верификация**
   ```
   /verify 123456
   ```
   - Код должен совпадать с тем, который установил администратор

3. **Главное меню**
   ```
   /start
   ```
   - Доступно только после верификации

4. **Получение документов**
   - Нажмите "Документы"
   - Выберите категорию
   - Выберите подкатегорию
   - Выберите документ

5. **Прохождение теста**
   - Нажмите "Тесты"
   - Выберите группу (2, 3 или 4)
   - Отвечайте на вопросы
   - Получите результаты

### Для администратора

**Важно:** Все админ-команды работают только для пользователя с ADMIN_ID

1. **Меню администратора**
   ```
   /admin
   ```

2. **Список зарегистрированных пользователей**
   ```
   /users
   ```

3. **Изменение кода безопасности**
   ```
   /setcode NEW_CODE_2024
   ```
   ⚠️ В текущей версии нужно также обновить .env

4. **Загрузка документов в базу**
   ```
   /load_docs
   ```
   - Сканирует папку `data/documents/` и добавляет файлы в БД

5. **Загрузка тестов**
   ```
   /load_tests
   ```
   - Сканирует папку `data/tests/` и загружает JSON файлы

## Формат тестов

Создайте JSON файл в папке `data/tests/`:

```json
{
  "name": "Тест по электробезопасности (Группа 2)",
  "group": 2,
  "questions": [
    {
      "question": "Какая минимальная группа по электробезопасности для выполнения работ под напряжением?",
      "options": [
        "Группа 1",
        "Группа 2",
        "Группа 3",
        "Группа 4"
      ],
      "correct_answer": 2
    },
    {
      "question": "Что необходимо сделать перед началом работы с электрооборудованием?",
      "options": [
        "Только визуально осмотреть",
        "Обесточить и проверить отсутствие напряжения",
        "Только надеть СИЗ",
        "Ничего не делать"
      ],
      "correct_answer": 2
    }
  ]
}
```

**Поля:**
- `name` - Название теста
- `group` - Группа электробезопасности (2, 3, 4)
- `questions` - Массив вопросов
  - `question` - Текст вопроса
  - `options` - Массив вариантов ответов
  - `correct_answer` - Индекс правильного ответа (1-4)

## Правила прохождения тестов

- ✅ **Успешное прохождение**: ≥90% правильных ответов
- 📊 Результаты показываются с подсветкой:
  - ✅ Зелёный - правильный ответ
  - ❌ Красный - неправильный ответ
- 📧 При успешном прохождении администратор получает уведомление

## Безопасность

### Уровни защиты:

1. **Корпоративный email**
   - Проверка домена email
   - Настройте свой домен в `core/auth_service.py`:
     ```python
     allowed_domains = ["intellektika.ru"]
     ```

2. **Код безопасности**
   - Устанавливается администратором
   - Хранится в `.env` (SECURITY_CODE)
   - Может быть изменён в любой момент

3. **Контроль доступа**
   - Документы доступны только после верификации
   - Тесты доступны только после верификации

## Устранение проблем

### Бот не запускается

1. Проверьте, что все зависимости установлены:
   ```bash
   pip install -r requirements.txt
   ```

2. Проверьте `.env` файл:
   - BOT_TOKEN должен быть валидным
   - ADMIN_ID должен быть числом

3. Проверьте логи бота в консоли

### Документы не загружаются

1. Проверьте структуру папок
2. Запустите `/load_docs` в боте
3. Проверьте права доступа к папкам

### Тесты не работают

1. Проверьте формат JSON файлов
2. Убедитесь, что файлы находятся в `data/tests/`
3. Запустите `/load_tests` в боте

### Пользователи не могут зарегистрироваться

1. Проверьте домен email в `core/auth_service.py`
2. Убедитесь, что код безопасности правильный
3. Проверьте логи бота
