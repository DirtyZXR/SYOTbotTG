# Система тестирования - переход на заглушки

## Описание
Все кнопки и функции, связанные с системой тестирования, переведены на заглушки с сообщением "В разработке".

## Изменённые компоненты

### 1. Главное меню
**Кнопка "📝 Тесты"**
- **Ранее**: Открывала меню выбора группы тестов
- **Теперь**: Показывает сообщение "В разработке"

### 2. Админ-панель
**Кнопка "📝 Сканировать тесты"**
- **Ранее**: Сканировала JSON файлы с тестами и добавляла в БД
- **Теперь**: Показывает сообщение "В разработке"

### 3. Команда `/load_tests`
- **Ранее**: Загружала тесты из папки data/tests
- **Теперь**: Показывает сообщение "В разработке"

### 4. Callback handlers
**test_group_**: Выбор группы теста
- **Ранее**: Показывала первый вопрос теста
- **Теперь**: Показывает сообщение "В разработке"

**answer_**: Ответы на вопросы теста
- **Ранее**: Записывал ответы пользователей
- **Теперь**: Показывает сообщение "В разработке"

## Заглушка "В разработке"

### Сообщение для пользователей:
```
📝 Система тестирования

⚠️ В разработке

Функционал тестирования находится в стадии разработки.
```

### Сообщение для администраторов (при сканировании):
```
📝 Система тестирования

⚠️ В разработке

Функционал тестирования находится в стадии разработки.
```

## Технические изменения

### bot/bot.py
1. **callback_menu** - обработчик action == "tests"
   - Заменён на показ сообщения о разработке
   - Сохранено логирование нажатия кнопки

2. **cmd_load_tests** - команда `/load_tests`
   - Заменена на показ сообщения о разработке
   - Сохранена проверка прав администратора

3. **callback_admin_load_tests** - callback "admin_load_tests"
   - Заменён на показ сообщения о разработке
   - Сохранена проверка прав администратора
   - Сохранено возвращение в админ-меню

4. **callback_test_group** - callback "test_group_*"
   - Заменён на показ сообщения о разработке
   - Убрана логика работы с тестами

5. **callback_answer** - callback "answer_*"
   - Заменён на показ сообщения о разработке
   - Убрана логика записи ответов

## Сохранённые компоненты

Следующие функции остаются на будущее развитие системы тестирования:
- `get_test_groups_keyboard()` - клавиатура выбора группы теста

## Пользовательский опыт

### Обычные пользователи:
1. Нажимают "📝 Тесты" → видят сообщение "В разработке"
2. Понимают, что функционал в разработке

### Администраторы:
1. Нажимают "📝 Тесты" → видят сообщение "В разработке"
2. Нажимают "📝 Сканировать тесты" → видят сообщение "В разработке"
3. Используют команду `/load_tests` → видят сообщение "В разработке"

## Преимущества такого подхода

✅ **Чистый код** - нет неиспользуемой функциональности
✅ **Ясность** - пользователи понимают статус разработки
✅ **Готовность** - сохранена инфраструктура для будущей реализации
✅ **Безопасность** - нет неработающего кода в продакшене
✅ **Логирование** - сохранены логи о попытках использования
