# Исправление проблемы с блокировкой кнопок

## Описание проблемы
После добавления глобального обработчика callback запросов перестали работать все кнопки в боте.

## Причина ошибки
Был добавлен глобальный обработчик `all_callback_handler`, который перехватывал все callback запросы и блокировал остальные обработчики:

```python
# ПРОБЛЕМНЫЙ КОД:
@dp.callback_query()
async def all_callback_handler(callback: CallbackQuery):
    """Глобальный обработчик для всех callback запросов"""
    logger.info(f"Callback received: {callback.data} from user {callback.from_user.id}")
    # Дает возможность другим обработчикам обработать этот callback
    # Этот обработчик будет вызван только если другие не обработали callback
```

### Почему это вызывало проблему:
1. В aiogram обработчики выполняются в порядке регистрации
2. Глобальный обработчик без фильтров регистрируется первым и перехватывает ВСЕ callback запросы
3. Обработчик не вызывает `await callback.answer()` или `return`, что может блокировать другие обработчики
4. Конкретные обработчики (с фильтрами) не получали callback запросы

## Решение
Удален глобальный обработчик `all_callback_handler`, так как:
1. Логирование уже добавлено в каждый конкретный обработчик
2. Глобальный обработчик блокировал нормальную работу кнопок
3. Необходимости в отдельном глобальном обработчике нет

## Как теперь работает логирование callback запросов:
Каждый конкретный обработчик имеет свое собственное логирование:

```python
# Пример для меню
@dp.callback_query(lambda c: c.data.startswith("menu_"))
async def callback_menu(callback: CallbackQuery, state: FSMContext):
    try:
        action = callback.data[5:]  # Убираем префикс "menu_"
        logger.info(f"Menu action received: {action}, User: {callback.from_user.id}, Full data: {callback.data}")
        # ... обработка
    except Exception as e:
        logger.error(f"Error in callback_menu: {e}", exc_info=True)

# Пример для админ-панели
if action == "admin_panel":
    logger.info(f"Admin panel button pressed by user {callback.from_user.id}")
    is_admin = AuthService.is_admin(callback.from_user.id)
    logger.info(f"User {callback.from_user.id} is admin: {is_admin}")
    # ... обработка
```

## Важное правило для aiogram обработчиков:
⚠️ **НЕ используйте глобальные обработчики без фильтров, если есть конкретные обработчики!**

Глобальные обработчики будут перехватывать все запросы и блокировать более конкретные обработчики.
